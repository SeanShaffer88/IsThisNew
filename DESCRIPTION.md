# IsThisNew? — Store listing description

**Forever added a timeline's worth of new things to a world you already know. Can you tell which is which?**

IsThisNew? adds one line to item and NPC tooltips in WoW: Forever:

- **Forever Exclusive** — this did not exist before Forever.
- **Changed in Forever** — you knew it in Classic, but it plays a new role here.

Hover the Cozy Sleeping Bag, the Truthseeker's Bow, Lyn the Ignored, or good old Archmage Ataeric (he's up to something new in Ambermill) and the tooltip tells you — with a short note and, if you turn it on, the guide the record came from.

And when it doesn't know? It says nothing. Untagged means *unknown* — IsThisNew? never guesses that something is "just Classic," because a small database can't prove a negative. Every one of its 35 launch records is transcribed from a cited Forever guide; none of its IDs are invented.

**Commands:** `/itin lookup <name>` asks the database from chat · `/itin dump` prints real item/NPC IDs to help grow the verified database · `/itin on|off|note|source|stats|debug`.

Tiny, free, open source (MIT), no libraries, no combat data, no automation. Forever only (interface 16001).

*Pre-launch note: v0.1.0 is built from beta-era guides and is awaiting verification in the live client after the November 4, 2026 launch.*
